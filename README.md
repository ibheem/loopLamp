# loopLamp

An agentic system with backend and frontend components.

## Project Structure

```
loopLamp/
├── backend/
│   ├── app/
│   │   └── main.py
│   └── agents/
├── frontend/
├── requirements.txt
└── .gitignore
```

## Components

### Backend
- Located in `backend/` directory
- Main application entry point in `backend/app/main.py`
- Agents logic in `backend/agents/`

### Frontend
- Located in `frontend/` directory

## Getting Started

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the backend:
   ```bash
   python backend/app/main.py
   ```

## Development

Add your agent implementations in `backend/agents/` and extend the main application as needed.
